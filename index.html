How It Works

Four systems. One signal.

Every signal FerroQuant generates is the output of a complete institutional-grade pipeline running in real time.

01

Regime Detection

HMM continuously classifies market state. Strategies are selected for current conditions.

02

Tournament Selection

178 strategies compete on live data using an ASHA successive halving algorithm.

03

ML Filtering

ONNX ensemble model — separate models for long and short — scores and filters every signal.

04

Live Execution

Entry, stop, and target levels delivered in real time. Paper trade to validate, then go live.
